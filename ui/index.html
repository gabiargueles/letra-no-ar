📘 Como criar seu app do Spotify (pra conectar)
  1. Abra o painel de desenvolvedor do Spotify e faça login:
  2. Clique em Create app.
  3. Nome e descrição: qualquer coisa (ex.: Letra no Ar).
  4. Em Redirect URIs, cole exatamente:
    http://127.0.0.1:3040/spotify e clique em Add.
  5. Marque Web API, aceite os termos e Save.
  6. Entre no app criado → Settings → copie o Client ID.
  7. Cole no campo acima e clique em Salvar. Pronto — agora é só Conectar o Spotify.
A letra vem do próprio Spotify (igual ao app). É só fazer login na janelinha — não precisa de app. Sem isso, uso LRCLIB/NetEase (às vezes fora de tempo).
Sem chave: uso o MyMemory (grátis, cota pequena). A chave fica só aqui no seu PC.
📗 Como conseguir a chave DeepL (opcional)
  1. Crie uma conta grátis no DeepL API (plano DeepL API Free):
  2. Precisa informar um cartão pra validar, mas o plano grátis não cobra (até ~500 mil caracteres/mês).
  3. Em Account → API keys, copie a Authentication Key (costuma terminar em :fx).
  4. Cole no campo acima e clique em Salvar. Sem isso, a tradução usa o MyMemory (grátis, mais limitado).
Conecte o Spotify nas opções (⚙️).
